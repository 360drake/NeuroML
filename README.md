# NeuroML
## Machine Learning MVPA, made easy

NeuroML is an interactive GUI program for conducting multivariate machine learning analysis, without the need to know Python and coding. By simplifying the process of model selection, training, and evaluation, users can easily utilize advanced analytical tools with little-to-no technical expertise. By integrating industry-standard machine learning practices in a robust framework, reproducible results are possible across a wide variety of methodologies. Evaulation scores and summary statistics are generated directly in the program, freeing up valuable time for researchers to review and interpret the results.

To run this program, first download a copy of the GitHub repository. Save the files to a folder that you can easily locate. It is recommended to create a virtual environment titled ".venv" in the folder as well. Before using NeuroML for the first time, make sure to install the required packages. Use the code block below to ensure all dependencies are installed before running NeuroML for the first time. For subsequent uses of the program, you can simply run the final line, "streamlit run NeuroML.py" from your terminal.

```bash
pip install -r requirements.txt

.venv\Scripts\activate.bat
streamlit run NeuroML.py
```
